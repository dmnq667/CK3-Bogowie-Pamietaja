## O modzie
Narracyjny mod do Crusader Kings III dla władców wiary słowiańskiej: dwanaście corocznych świąt, około 120 wariantów, sądy bogów, Księga Bogów, objawienia Welesa, Mokoszy i Peruna oraz historie o odroczonych skutkach czynów i relacji. Polska i angielska lokalizacja.
